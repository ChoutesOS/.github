# Security Policy

## Supported versions

Security fixes are delivered through the ChoutesOS package repository. Keep your system up to date to receive them.

## Reporting a vulnerability

Do not post security vulnerabilities in public channels, issues, or pull requests.

Join the [ChoutesOS Discord server](https://discord.gg/nYdsKv7Fra) and send a direct message to a member of the ChoutesOS team. Please include:

- A description of the vulnerability and its possible impact
- The affected component and version
- Steps to reproduce, or a proof of concept
- Any suggested fix or mitigation

We will acknowledge your report as soon as we can, keep you informed about progress, and credit you when the fix is published, unless you prefer to remain anonymous.

## Scope

This policy covers ChoutesOS-specific code, configuration, packaging, and infrastructure.

Vulnerabilities in upstream software, such as Arch Linux packages, the Linux kernel, KDE Plasma, or Calamares, should be reported to the respective upstream projects. If a ChoutesOS configuration makes an upstream issue easier to exploit, please report that to us as well.
